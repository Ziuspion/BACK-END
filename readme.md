## O que é JavaScript?

JavaScript é uma linguagem de programação usada principalmente para tornar páginas da web interativas e dinâmicas.

Ela funciona junto com HTML e CSS:

- HTML = estrutura da página
- CSS = visual/estilo
- JavaScript = comportamento e interatividade

### Exemplos do que ele faz:
- abrir e fechar menus
- validar formulários
- mudar texto na tela
- criar animações
- buscar dados de um servidor
- criar jogos e aplicações web

### Onde ele é usado?
- páginas web
- apps front-end
- servidores com Node.js
- automação e ferramentas de desenvolvimento

### Exemplo simples:
```javascript
let nome = "Maria";
console.log("Olá, " + nome);
```

Isso imprime no console:
```javascript
Olá, Maria
```

### Diferença de JavaScript para Java
São linguagens diferentes, apesar do nome parecido. JavaScript não é Java.

### Resumindo
JavaScript é a linguagem que dá vida ao site, permitindo que ele responda ao usuário, atualize conteúdo e execute ações em tempo real.
